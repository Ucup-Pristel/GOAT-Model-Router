# GOAT Model Router v0.1.0-beta.1

This first public beta brings GOAT Model Router to OpenCode through native plugin installation. The Manager routes scoped work to manually assigned Workers; a separate Auditor reviews test evidence before OpenCode asks permission to apply verified edits. The portable core and the OpenCode adapter ship together through an exact npm dependency.

After publication, install for all your workspaces:

```sh
opencode plugin add @goatmr/opencode@beta
```

In the OpenCode terminal, run `/goat status`. Fresh storage starts OFF. Use `/goat router` to choose models, `/goat mode` to select Standard for ordinary workspaces, and `/goat on` to activate. Use `/goat off` to deactivate. Existing model connections and permissions remain under OpenCode's control. GOAT settings are shared across workspaces using the same host database.

**Tested target:** OpenCode 2.4.2 TUI on Linux x86-64. Ordinary verified write-back supports bounded Python `unittest` suites and requires the Linux facilities described in the README. Passing the protected tests is not a guarantee of correctness; multi-file write-back is not atomic. There is no desktop GUI integration.
