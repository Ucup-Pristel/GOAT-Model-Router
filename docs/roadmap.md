# Roadmap to the first public beta

| Milestone | Outcome |
|---|---|
| Configuration and Manager decisions | Persistent opt-in controls and role assignments; intent-preserving Standard and Resink planning; capability-tier routing. |
| Verified execution | Scoped Workers, protected checks and a separate Auditor, first for single-file tasks and then for multi-file projects. |
| Parallel orchestration | Dependency-aware scheduling, scoped snapshot integration, shared request budgets and one bounded rework round. |
| Workspace execution | Native discovery and permissions in OpenCode Build, followed by conflict-checked application of verified edits. |
| Portable core | Planning and execution contracts separated from host-specific sessions, permissions, verification and writes. |
| Distribution | Matched npm packages with native global and project-local installation tested on the supported OpenCode host. |

The current release milestone is [`0.1.0-beta.1`](releases/v0.1.0-beta.1.md). The candidate packages and installation lifecycle have been validated; public npm publication and the GitHub pre-release are pending. The [compatibility guide](compatibility.md) defines the scope of the beta.
