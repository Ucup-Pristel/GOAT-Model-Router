# GOAT orchestration core

GOAT's portable planning, routing, scheduling and evidence checks. Node ESM,
with TypeScript declarations. For the native OpenCode plugin, install
`opencode plugin add @goatmr/opencode@beta` after beta publication; the adapter
selects the matching core version.

[Architecture and host contract](https://github.com/Ucup-Pristel/GOAT-Model-Router/blob/main/docs/architecture.md#execution-host-contract)
