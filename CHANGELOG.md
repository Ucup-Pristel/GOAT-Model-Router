# Changelog

## 0.1.0-beta.1 — first public beta candidate

- Ships the portable ESM core as `@goatmr/core` and the native OpenCode adapter as `@goatmr/opencode`. Installing the adapter resolves the exact core version.
- Supports global beta installation and per-project version pins. Fresh storage starts OFF; activation, mode and model assignments persist across workspaces on the same host database.
- Includes the Apache-2.0 license and project notices in both npm packages.

See the [beta release notes](docs/releases/v0.1.0-beta.1.md) for installation and platform limits.
