# Security

Report issues affecting the current beta privately. In particular, report permission bypasses, unintended workspace writes or exposure of provider data without posting the details in a public issue.

Use [GitHub private vulnerability reporting](https://github.com/Ucup-Pristel/GOAT-Model-Router/security/advisories/new) if enabled. If the form is unavailable, ask a repository maintainer for a private channel via a public issue titled “Private security contact requested”; omit vulnerability details.

In the private report, include affected versions, platform, expected and observed behavior, and a minimal reproduction with synthetic files. Remove tokens, OAuth data, private prompts, project content and identifying paths. Do not send provider credentials or a host database.
